# Project Context

CRM Hygiene Agent helps revenue teams keep CRM records accurate, complete, and reviewable. The product focuses on deal hygiene signals, evidence-backed recommendations, approval workflows, and auditability before automated updates are made to CRM data.

## Stage 0 Scope

Stage 0 establishes the application scaffold only. It does not implement CRM integrations, production data models, agent orchestration, authentication, or deployed infrastructure.


## Stage 1 Direction

Stage 1 is `Stage 1 — Data Model and Seed Fixture Data`. It should introduce Prisma application models, deterministic seed fixture data, and related unit/integration tests only. CRM adapters, live CRM ingestion, agent orchestration, and approval workflows remain out of scope for Stage 1.
