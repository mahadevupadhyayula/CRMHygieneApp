# Stage 00 — Project Setup

## Goal

Create a runnable Next.js + TypeScript scaffold with baseline tooling, tests, docs, and required directory structure.

## Acceptance Criteria

- Next.js App Router project files exist at the repo root.
- Prisma, Zod, Vitest, and Playwright are configured.
- Required application, component, library, Prisma, test, and docs directories exist.
- Homepage renders the product name and product principle.
- Vitest, Playwright, and Prisma validation checks are available.
